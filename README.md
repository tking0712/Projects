# Technical Projects

Selected academic and personal projects completed during my B.S. and M.S. programs.

## Raspberry Pi Environmental Monitoring System
Kennesaw State University — May 2024

Built a Raspberry Pi 5 environmental monitoring system using a DHT11 sensor and Python.
Collected temperature and humidity readings, timestamped results, logged data to CSV, and
supported remote administration and troubleshooting.

Technologies: Python, Raspberry Pi, GPIO, DHT11, CSV

## Bank Customer Churn Prediction
Kennesaw State University — November 2024 | Team Project

Developed and evaluated machine-learning models using bank customer churn data.
Work included preprocessing, feature preparation, train/test splitting, transformation
pipelines, Random Forest modeling, hyperparameter tuning, and model evaluation.

Technologies: Python, pandas, scikit-learn, Random Forest, GridSearchCV

Note: These projects were completed prior to being uploaded to GitHub; the repository was created later as a portfolio/archive of prior coursework.
